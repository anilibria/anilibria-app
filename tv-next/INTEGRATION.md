# Новый TV-клиент рядом с существующими приложениями

Каталог `tv-next/` — самостоятельный Gradle-проект. Он не подключается к корневому `settings.gradle.kts` и не меняет сборку мобильного или прежнего TV-клиента.

Сборка из корня репозитория:
```sh
cd tv-next
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleRelease
```

Требуются JDK 17 и Android SDK 36. Новый пакет — `tv.aniliberty.next`, минимальная версия Android — 8.0. Он устанавливается рядом со старыми приложениями, без автоматической миграции их данных.

Все прежние файлы исходного `develop`, включая `app-mobile`, `app-tv`, общие модули, корневые Gradle-файлы и Gradle Wrapper, сохранены без изменений. CI нового клиента находится в отдельном файле `.github/workflows/tv-next.yml` и собирает только проект в `tv-next/`.

Основное описание: [README.md](README.md). Авторизация и ограничения: [docs/ACCOUNT-FEATURES.md](docs/ACCOUNT-FEATURES.md).

Во время воспроизведения и буферизации с намерением продолжать просмотр плеер удерживает экран включённым через нативный `View.keepScreenOn`. При паузе, завершении, ошибке или уходе из плеера это удержание снимается. Системные настройки телевизора не изменяются.
