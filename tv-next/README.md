# AniLiberty TV Next

Новый Android TV клиент в ветке `rewrite/tv-next`. Это отдельная кодовая база с нуля: один модуль `app`, без старого `app-tv`, Leanback, Quill, старых моделей и PHP API. Из предыдущего проекта сохранены только лицензия и Gradle Wrapper.

Визуальный источник — страница релиза AniLiberty из предоставленного HTML-архива. Навигация рассчитана на пульт: стрелки выбирают вкладку, OK / ↓ переносят в содержимое, ↑ из первого ряда возвращает к вкладкам. Заголовки не получают фокус.

Главная: горизонтальные полки новых эпизодов, расписания, франшиз, жанров и видео. В новых эпизодах, расписании и видео — до девяти элементов и стрелка «Все». В жанрах — четыре случайные карточки, во франшизах — три, «Обновить» и «Открыть все»; обновление касается только выбранной подборки. Жанры и франшизы выбираются случайно и сохраняются при возврате. Постеры с читаемыми подписями под изображением; широкие карточки для остальных типов. Торренты доступны только через «Ещё» в релизе, загружаются по запросу. Статические Montserrat SemiBold 600 / Inter Regular 400, лицензии — docs/fonts.

Первая рабочая сборка: стартовый экран, последние обновления, каталог с поиском, панелью фильтров и непрерывной догрузкой, тайтл, эпизоды с превью и длительностью, команда, Media3 HLS-плеер с выбором качества и серии. Прогресс сохраняется по UUID эпизода. Локальная библиотека не связана с серверным избранным.

Реализованы вход по коду/QR, профиль, серверные списки и синхронизация прогресса, история и управление устройствами. Плеер поддерживает продолжение, переход между сериями, выбор качества и предложения пропуска. Обсуждение открывается на сайте. Внешние каталоги не подключены.

Первый запуск — отдельный приветственный экран с выбором: QR-код, логин и пароль или гость. Пароль используется только для запроса токена и не сохраняется. При следующих запусках сразу открывается главная. Начальная загрузка и ошибка подключения оформлены отдельно, с повторной попыткой без сброса настроек.

## Сборка

JDK 17, Android SDK 36:

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug
```

Пакет `tv.aniliberty.next`, APK `app/build/outputs/apk/debug/app-debug.apk`. Устанавливается рядом с предыдущим приложением. Данные предыдущего клиента не мигрируются и не удаляются.

В плеере кнопка MENU открывает выбор серии и качества. Экранные контролы скрываются через 3 секунды. Недоступные HLS-потоки не подменяются внешними источниками.

Иконки и оригинальный знак подключены из переданного UI-kit: [происхождение и интеграция](docs/UI-KIT-INTEGRATION.md).

«Продолжить просмотр» на главной запускает конкретную серию по UUID: незаконченный эпизод или следующий доступный после завершения. История и метаданные хранятся локально, HLS-адреса не сохраняются.

## Подготовка релиза

Проверка: `./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleRelease`.
CI сохраняет debug APK, неподписанный release APK и отчёты проверок. Release APK нужно подписать постоянным ключом владельца перед распространением. Ключи в репозиторий не добавляются.

Перед выпуском проверить на телевизоре: чистую установку и кнопку OK на приветствии, повторный запуск, запуск без сети и повторную попытку, вход по QR, запуск серии и восстановление прогресса. Автоматическая сборка не заменяет проверку реальным пультом.

В настройках воспроизведения (в плеере и в общих настройках) можно выбрать, после какой доли серии считать её просмотренной: 50–100% с шагом 5%, по умолчанию 90%. Отметка используется в списках серий, «Продолжить просмотр» и синхронизации с аккаунтом. Фактическая позиция сохраняется, воспроизведение при достижении порога продолжается.
