# Аудит экранов Android TV — 22.10.2026

Проверены код всех текущих экранов, общий адаптер, навигация, состояния данных и плеер. Это аудит реализации: проверку на реальном телевизоре и живых видеопотоках он не заменяет.

| Экран | Результат |
| --- | --- |

| Главная | Сохранены согласованные полки, карточки и восстановление позиции. Меню удержания OK унифицировано. |
| Каталог | Сохранены 4 колонки, встроенный поиск, фильтры и настоящая пагинация. |
| Новые эпизоды | Периоды за последний месяц, горизонтальные полки 4,5 карточки. Пагинация каталога вместо увеличения limit. |
| Жанры, франшизы, видео | Сохранены отличающиеся структуры и общий поиск/стиль; ширина меню больше не меняет контент. |
| Состав франшизы | Горизонтальный ряд в серверном порядке; исходные пропорции постеров, без нумерации. |

| Диалоги | Общее оформление описания, быстрых действий, ошибок и дополнительных источников. Длинные заголовки не вытесняют действия за экран. |

## Проверка

Robolectric: последовательная компоновка каталога, пустой/заполненной библиотеки, франшизы, разделов, всех четырёх вкладок тайтла и возврата на главную. Сохранены существующие проверки пагинации, фокуса, истории и серий. CI выполняет unit-тесты и сборку APK.

## Практические ограничения

- Авторизация и серверные коллекции не реализованы; библиотека этого телевизора не выдаётся за аккаунт AniLiberty.
- Поиск в жанрах/франшизах работает по полным спискам. Видео ограничены возможностями текущего API; область поиска обозначена в интерфейсе.
- Для месячной ленты источник — релизы с последним обновлённым эпизодом, а не исторический журнал каждого опубликованного эпизода.
- Перед следующими визуальными правками нужны снимки текущей версии на ТВ: высота клавиатуры, обрезка изображения и доступность внешнего видеопотока зависят от устройства/сети.
