# Подключение переданного UI-kit

Источник: `AniLiberty_AndroidTV_COMPLETE_UI_KIT(1).zip`, 22.10.2026. Архив прочитан как данные. Вложенный загрузчик официальных репозиториев не запускался.

## Применено

- Оригинальный знак `AniLiberty_logo_brand_red_ORIGINAL.svg`: пути без перерисовки конвертированы в Android VectorDrawable `ic_aniliberty`. Он заменяет временную букву A в боковом меню.
- Bootstrap SVG: search / house-door / collection-play / bookmark-heart заменяют системные значки меню; также подключены play/pause, previous/next, refresh, arrow, episodes, related, team, favorite, comments, settings.
- SVG-глифы в архиве имеют viewBox 300×300 и отражённую группу `translate(0 300) scale(1 -1)`. Преобразование сохранено в vector group; пути не перевычислялись и не упрощались.
- Цвета `#121212`, `#212121`, `#424242`, `#FE3635`, `#FFFFFF`, `#B4B4B4`; копия таблицы Android-цветов — `brand_colors.xml`. Вторичный текст обновлён до #B4B4B4.
- Карточки получают радиус 12dp и рамку фокуса 2dp из TV-адаптера. Кнопки «Обновить / Открыть все» — поверхность #212121, красная иконка, белый фокус. Нативная геометрия TV не приравнивается к CSS px.
- Фирменные шрифты уже поставляются статическими Inter Regular / Montserrat SemiBold. В UI-kit бинарных шрифтов нет, текущие файлы сохранены.
- Уведомление Bootstrap MIT включено в APK: `assets/licenses/bootstrap-icons.txt`. Оригинальный SVG логотипа сохранён в документации.

## Приоритет решений

Сначала последние указания пользователя: 3 франшизы / 4 жанра, собственное Обновить + Открыть все, горизонтальные полки. Затем композиции оригинальных компонентов сайта (жанр с нижним текстом в изображении; франшиза из двух частей; latest-overlay по фокусу). Общие TV CSS из архива используются как адаптер оформления, не подменяют эти композиции одной универсальной карточкой.

Все 1522 иконки и CSS Vuetify в APK не включаются: добавлены используемые нативные ресурсы. CSS/JS не выполняются внутри приложения. Плеер сохраняет Media3 и исходные HLS; новые пиктограммы не изменяют контракт API.

Проверка: загрузка векторных ресурсов, содержимое карточек/полок, сборка APK. Визуальная приёмка на реальном ТВ после этого прохода ещё не выполнена.


## Увеличение главной

По следующему указанию пользователя карточки горизонтальных полок увеличены примерно на 18% с соответствующим увеличением шрифтов и высоты полок. Заголовки главной — 24sp. Каталог и полные страницы сохраняют собственную плотность. Заголовок расписания и кнопки Вчера / Сегодня / Завтра находятся в одном горизонтальном контейнере; заголовок не получает фокус, выбор дня ведёт к соответствующему ряду.

## Значок аккаунта

`ic_account.xml` использует геометрию `app-mobile/src/main/res/drawable/ic_person.xml` оригинального `anilibria/anilibria-app` (GPL-3.0). Цвет адаптирован к белым TV-иконкам. Ресурс применяется для профиля, входа и данных аккаунта. Исходный мобильный ресурс не изменён.
