# Основа нового клиента

Архив страницы «Семь рыцарей королевства Марронье» разобран без исполнения JS. Полный инвентарь 977 тегов — WEB-DOM-BY-TAG.md. 22 CSS-файла и 3 встроенных style содержат 7417 правил / 13617 деклараций. Сопоставленные правила — WEB-CSS-RULES.md; это исходный CSS, не computed style.

| Оригинал | Установлено из DOM/CSS | Новый ТВ-компонент |
|---|---|---|
| `.v-row.mb-4` + постер `.v-col-md-4` + информация `.v-col-md-8` | Постер слева, справа названия, возраст/день, метаданные, кнопка просмотра | Шапка с постером 174×250 dp; правая колонка с заголовком и основной кнопкой |
| `.ff-heading` / `.ff-body` | Montserrat / Inter | Встроены оригинальные Montserrat / Inter из Google Fonts (OFL), включая кириллицу; заголовки / основной текст разделены |
| `.v-theme--dark` | Фон #121212, поверхность #212121, secondary #FE3635 | Палитра клиента из этих значений |
| `.v-tab.v-tab.v-btn` | border-radius: 0, min-width 90px; comfortable height 44px | Строка 42 dp + линия 2 dp, без стандартных Android Button |
| `.v-tab__slider` | Индикатор 2px, цвет currentColor, виден только у выбранного | Красная линия только у активного раздела; светлая подложка только у фокуса |
| `a.v-tab` | Эпизоды, Связанное, Работа над релизом, Торренты | OK / ↓ активирует раздел и переносит фокус в содержимое |
| `button.v-btn--disabled` | Комментарии отключены в этом конкретном архиве | Не выдаём веб-переход за нативные комментарии: временно явная ссылка на обсуждение |
| `.v-col-sm-6.v-col-md-4` | Сетка превью: 3 колонки на десктопе, 2 на планшете | 3 колонки эпизодов на ТВ, каждый эпизод — одна цель фокуса |
| `.v-progress-linear` | Нижняя полоска 3px, прогресс дробный | Прогресс по сохранённой позиции UUID; не подменяется флагом «когда-либо смотрел» |
| `.poster-as-background` | opacity .09, высота 500px; затемняющий градиент | Фоновая обложка в первой новой сборке ещё не реализована |
| Новые эпизоды / Рекомендуем | Самостоятельные блоки с заголовками без карточечного фона; на широком вебе боковая колонка | Главная — новая сетка обновлений. Рекомендации на странице релиза ещё не реализованы |

Границы первой сборки описаны в README. Не переносим рекламные блоки, скрытые меню аккаунта, трекеры и footer на каждый ТВ-экран. Не обещаем полный перенос личных коллекций до реализации Bearer-авторизации и проверки контракта.
